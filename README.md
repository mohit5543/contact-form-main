# 📬 Contact Form | Frontend Mentor Challenge

This is a solution to the [Contact Form Challenge](https://www.frontendmentor.io/challenges) on Frontend Mentor. It's a clean and functional contact form that includes field validation and interactive UI feedback.

## 🚀 Overview

### ✅ Features

Users are able to:

- Fill in their **First Name**, **Last Name**, and **Email Address**
- Choose a **Query Type** (General Enquiry or Support Request)
- Enter a **Message**
- Tick a **Consent checkbox** to allow contact
- Submit the form and see a **success confirmation message**
- View proper error messages for invalid or incomplete fields
